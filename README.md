# VicWebOs

Sistema operativo web para grupos chicos: parejas, amigos, familias.

---

## ¿Qué es?

VicWebOs es un "sistema operativo" que vive en el navegador. Tiene
apps instalables, temas intercambiables y widgets configurables. Está
pensado para grupos de 2 a 8 personas que quieran tener su propio
espacio digital compartido.

---

## ¿Cómo funciona?

Cada grupo (o "comunidad") conecta un repositorio privado de GitHub
donde se guardan todos los datos. Vos sos el dueño de esa información.
VicWebOs no tiene servidores propios, no guarda nada, no ve nada.

El código se comparte entre todos los grupos: cuando se actualiza, se
actualiza para todos. Los datos son privados e independientes por grupo.

---

## Cómo usarlo

1. Abrí VicWebOs desde GitHub Pages o localmente.
2. Conectá una comunidad con tu token de GitHub.
3. Creá tu cuenta (nombre, código único, foto opcional).
4. Abrí **Stor-He** y empezá a instalar apps.
5. Compartí el link con tu grupo. Cada uno crea su cuenta en la misma
   comunidad y empiezan a interactuar.

---

## Qué incluye

- **Apps**: chat, correo, red social, editores, juegos, calculadora,
  bloc de notas, y más.
- **Temas**: más de 20 estilos visuales distintos.
- **Widgets**: reloj, radio, mascotas, atajos rápidos, y más.

Todo se instala desde la tienda interna. Nada viene de fábrica más
allá del sistema básico.
