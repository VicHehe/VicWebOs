================================================================
  REGLA 4 — TEMAS
================================================================

Cada tema vive en:
    VicWebOs/Temas/{nombreTema}.css

CARACTERÍSTICAS:
    - UN ARCHIVO CSS por tema. Nada más.
    - Se carga en index.html así:
        <link rel="stylesheet" href="Temas/{nombre}.css" id="tema-activo">
    - Para cambiar de tema, se intercambia el href del <link>
      con id="tema-activo" (ver Cuenta.js → aplicarTema()).
    - El tema puede sobreescribir CUALQUIER regla CSS del
      style.css base: colores, tamaños, layout, tipografía,
      sombras, animaciones, TODO.
    - Como mínimo, todo tema debe definir las variables del
      :root (--violet-XXX, --bg, --bg-alt, etc.) para no
      romper la UI.
    - Si un tema NO define el layout, hereda el del style.css
      base automáticamente.

TEMA BASE OBLIGATORIO:
    Temas/violeta.css — fondo blanco, violeta clásico.
    Es el default. Se carga siempre al iniciar VicWebOs si
    no hay otro guardado en la cuenta.

REGLAS:
    - Nombre del archivo en minúsculas: violeta.css, no Violeta.CSS
    - Sin subcarpetas dentro de Temas/
    - Sin imágenes/iconos propios (si algún tema los necesita,
      se suben al repo de datos y se referencian por URL completa)
    - Registrar en JsTemas.js con:
        { id, nombre, icono, descripcion, categoria, esBase, ruta }

================================================================
  REGLA 5 — WIDGETS
================================================================

Cada widget vive en:
    VicWebOs/Widgets/{nombreWidget}/
        index.html
        style.css
        script.js

CARACTERÍSTICAS:
    - Misma estructura que las apps (Regla 3)
    - Los widgets se renderizan dentro de la welcomeScreen del
      OS (o donde el usuario los coloque), no en pestañas.
    - El padre comunica con el widget vía:
        iframe.contentWindow.postMessage()  o
        window.parent.__vicwebos.*
    - Los datos del widget, si los necesita, van en:
        vicwebos-data/app/{nombreWidget}/
      con el mismo patrón que cualquier app (Regla 1).

REGLAS:
    - Nombre de carpeta en minúsculas con guiones: reloj-mundial
    - Nombres fijos: index.html, style.css, script.js
    - Registrar en JsWidgets.js con:
        { id, nombre, icono, descripcion, categoria, esBase, ruta }

================================================================
  API DISPONIBLE (recordatorio)
================================================================

En el shell (index.html + js/):
    window.__vicwebos.obtenerCatalogo()   → apps
    window.__vicwebos.obtenerTemas()      → temas
    window.__vicwebos.obtenerWidgets()    → widgets
    window.__vicwebos.aplicarTema(id)     → cambia tema
    window.__vicwebos.instalarTema(id)
    window.__vicwebos.instalarWidget(id)
    ...

En apps/widgets (iframes):
    window.parent.__vicwebos.*

En datos (JSON):
    ConfigBD.leerArchivo(path)
    ConfigBD.escribirArchivo(path, data)
