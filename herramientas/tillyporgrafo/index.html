Cómo usar TillyPorgrafo

Diseñá cada letra y exportá tu fuente como archivo TTF compatible con Word, Photoshop, Figma y navegadores.

Paso a paso

  • 1. Elegí una letra en el panel "Letras"
  • 2. Dibujala con el lápiz sobre el lienzo
  • 3. Repetí para todas las letras que quieras incluir
  • 4. Tocá "Exportar" y descargá el .ttf

Las guías de referencia

  • Ascendente: arriba de letras altas (b, d, h, k, l)
  • Mayúscula: techo de las mayúsculas (A, B, C…)
  • x-height: techo de minúsculas normales (a, c, e…)
  • Base: donde se apoyan las letras
  • Descendente: abajo de letras con cola (g, p, q, y, j)
